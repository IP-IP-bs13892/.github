<h2>为什么不是「越贵越好」</h2>
<p>资源有溢价层级：普通住宅、ISP 住宅、双 ISP、原生独享。每一层都更贵、更稀缺。但边际收益是递减的：从「共享」升到「独享」，收益明显；从「独享」升到「双 ISP」，收益就很有限了。</p>
<p>多数店铺的最优落点是「独享静态住宅」，不需要再往上加。把省下的预算花在环境与资料上，收益更高。</p>

<h2>选型要避开的三种「高级」</h2>
<p>一是为了「听起来专业」选最贵的档。贵不等于匹配。二是为了省钱选机房地址再套伪装。这类地址的归属特征很难改。三是为了灵活选动态地址做长期店铺。地址一变，环境就要重配。</p>
<p>三种都属于「判断标准错位」：把价格或概念当成判断依据，而不是把自己的实际需求当成依据。</p>

<h2>美国住宅 IP 配置四步</h2>
<p>第一步，拿到资源后先验：归属州或城市是否与店铺市场一致、类型是否标为住宅、是否独享。第二步，建立独立环境：浏览器配置、时区、语言与地址地区对齐。</p>
<p>第三步，接入网络：在客户端里填好连接信息，测试通路。第四步，验证一致性：查出口地址、查解析来源、看指纹参数是否与设置相符。</p>

<h2>电脑端配置要点</h2>
<p>如果用的是独立浏览器环境，把代理配置写在环境里，而不是系统全局。这样其他环境不受影响，也便于按店铺切换。</p>
<p>时区要跟着地址走，语言建议一并设置。屏幕分辨率这类硬件参数如果多环境相同，反而是个相似点，值得留意。</p>

<h2>手机端配置要点</h2>
<p>手机配置比电脑简单，但更容易出问题：系统级的代理设置会影响所有应用，切换店铺时要记得改回来。另外手机在 Wi-Fi 与移动数据之间切换时，代理可能失效。</p>
<p>建议为不同店铺准备不同的配置方案，避免手动切换出错。手动操作越多，出错概率越高。</p>

<h2>配好后的验证</h2>
<p>三查：出口地址是否是预期的那一个。解析来源是否与出口一致。环境参数（时区、语言、分辨率）是否与地址地区匹配。</p>
<p>三查都过，才算配好。只查第一项，很容易漏掉解析与环境不一致的问题。</p>

<h2>三个常见配置错误</h2>
<p>一是代理配了但环境没配，结果地址是美国的、时区是北京时间。二是解析没跟着走，暴露了真实位置。三是多个环境共用一套浏览器配置，指纹相似。</p>
<p>三个错误的共同点是「只做了一半」。配置这件事，做完一半比不做更危险，因为你会误以为已经做好了。</p>
